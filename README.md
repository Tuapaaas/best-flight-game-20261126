Skylark Courier — an original 2D flight game that plays offline in a desktop browser from its own files. Fly the Dawn Runner across the Lumen Archipelago: deliver parcels to island strips, thread eight golden rings, and land home before the fuel gauge hits empty. Keyboard and mouse, with a lit HUD (altitude, speed, heading, fuel, hull, compass, attitude indicator and minimap), storm clouds that chew the hull, and a stall model that punishes lazy throttle hands.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press FLY. No build step, no network request — every file the game loads lives under game/.
